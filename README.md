## Android 설치

1. **Download APK**를 눌러 휴대폰에서 파일을 다운로드합니다.
2. 다운로드한 파일을 엽니다. 설치 권한 안내가 나오면 사용한 브라우저 또는 파일 앱에 ‘이 출처 허용’을 설정합니다.
3. 설치 후 Skull King을 실행합니다. 기존 앱이 있으면 업데이트로 설치됩니다.

Android 7.0 이상, 64비트 ARM 또는 x86 기기가 필요합니다. 별도 서버 주소 입력 없이 기본 게임 서버로 연결됩니다.

## iOS 설치

1. App Store에서 Apple의 **TestFlight** 앱을 설치합니다.
2. 위 **Join TestFlight** 링크를 열고 테스트에 참여한 뒤 설치합니다.

사전 기기 등록은 필요하지 않습니다. TestFlight에 이전 빌드가 설치되어 있으면 **Update**를 눌러 최신 빌드로 맞춰 주세요.

## 친구와 플레이

**Create Room**으로 방을 만들고 초대 코드를 공유하세요. 친구는 **Join Room**에서 코드를 입력하거나 카메라 버튼으로 대기방의 바코드를 읽어 입장합니다. 참가자 2–7명이 모이고 실제 플레이어가 모두 Ready하면 시작합니다. 방장은 **Add Bot**으로 빈자리를 채울 수 있어, 실제 플레이어 한 명과 Bot으로도 시작할 수 있습니다. 만석인 대기방에 사람이 입장하면 가장 먼저 추가한 Bot의 자리를 대신합니다.

29번 Android는 플레이어 칸을 내용에 맞게 줄이고 **닉네임·Waiting·Ready를 포함한 칸 전체**에 총알자국을 표시합니다. 보이는 자국의 누적 겹침은 **60% 미만**, 총알은 **10발**이며 공간이 없으면 차감하지 않습니다. Bot 제거 버튼의 터치는 유지합니다. Bot·탈주 AI는 차례마다 **3~5초** 중 한 번 뽑은 시간에 카드를 냅니다. 손패는 **700ms 안에 순서대로 뒤집어 공개**한 다음 전체 **15+n초 Bidding**을 시작합니다. Android 카드에는 원본 그림에서 만든 표시용 사본을 사용해 첫 공개 중 빈 그림이 보이던 문제를 개선했습니다. 현재 설치 가능한 앱은 **Android29·iOS28**이며 iOS29 공개 준비도 진행 중입니다. 두 앱은 같은 서버에서 플레이할 수 있습니다.

28번 Android·iOS는 대기방 닉네임과 상태 사이 간격을 줄이고, 게임 시작 시 최소 **3초 로딩 후 전체 Bidding 시간**을 제공합니다. 카드 제출 표시와 실제 카드 이동을 개선합니다. 원래 카드 그림·마모와 목재 UI는 유지합니다. 28번 공개 때 Android28·iOS28을 제공했으며, iOS28은 공개 TestFlight Friends Preview에서 테스트할 수 있습니다. 이 문단은 당시 배포 이력입니다.

27번 Android는 대기방 총알자국의 누적 겹침 면적을 각 자국의 **60% 미만**으로 제한하고, 표시 영역을 **닉네임까지** 넓혔습니다. Waiting·Ready 상태와 Bot 제거 버튼은 자국 영역 밖에 유지합니다. 공간이 없으면 총알을 차감하지 않습니다. Android27 공개 당시 iOS는 **26번**이었고 **iOS27은 공개하지 않았습니다**. 당시 Android27과 iOS26의 함께 플레이를 지원했으며, 해당 표시 영역과 겹침 기준은27번 앱에 적용했습니다.

26번 Android·iOS에는 목재 주요 버튼·현재 플레이어 명패·선택 Bidding, 타이그리스 카드 뒤집기, 제출 카드 이동과 잉크 착지, 카드 속 소극장 로딩이 추가됐습니다. 원래 카드 그림과 마모는 유지합니다. iOS26도 Apple 승인 후 공개 TestFlight로 배포했습니다. 당시 Android26·iOS26의 함께 플레이를 지원했습니다.

25번은 대기방 총알자국이 서로 **40% 이상 겹치지 않도록** 배치합니다. 공간이 없으면 총알을 차감하지 않으며, 치유하거나 다른 플레이어에게 사용할 수 있습니다. 방장은 Bot 옆의 **×** 버튼으로 특정 Bot을 제거할 수 있습니다. 참가자가 바뀌면 다시 Ready를 눌러 주세요. 이 기능에는25번 앱으로 업데이트가 필요합니다.

24번은 대기방 도구를 마모 질감의 플로팅 캡슐로 정리했습니다. 총알은 입장당 **10발**이며 아이콘 오른쪽 아래에 남은 수를 표시하고, 치유에는 **∞**를 표시합니다. 나가기는 오른쪽 독립 버튼을 누른 뒤 확인합니다.

23번은 Bot·탈주 AI도10초 타이머를 표시하고5초 뒤 카드를 냅니다. 시간 바는1초 단위로 줄어들고, 제출 카드 목록은 새 카드로 이동하며 상단 플레이어 목록은 직접 옮긴 위치를 유지합니다.

22번 Android는 초대 카메라를 정사각형으로 확대하고 바코드 가이드를 중앙에 맞췄습니다. iOS22도 같은 카메라 업데이트를 제공합니다. 실제 렌즈의 초점 속도 향상은 아직 측정하지 않았습니다.

21번 Android·iOS에는 대기방 총알·치유 도구가 추가됐습니다. 다른 플레이어 상자를 눌러 총알자국을 남기거나 낡은 붕대로 치유할 수 있습니다. 21번의 총알5발·개수 미표시는24번부터10발·남은 수 표시로 바뀌었습니다. 치유는 무제한이고 본인 상자에는 두 도구 모두 사용할 수 없습니다.

방장은 대기방에서 Bot을 추가할 수 있습니다. Bot과 탈주 AI는 같은 Bidding·카드 선택 규칙으로 판단하고 10초 제한을 표시하며 자기 차례마다3~5초 중 한 번 뽑은 시점에 제출합니다. 서버와 앱의 남은 시간 보정을 유지합니다. 타이그리스를 처음 받으면 기본 그림으로 표시하고, 카드 위 원을 누르면 해적·도주 전용 그림으로 전환합니다.

테스트 서버는 현재 개발용 데스크톱에서 운영 중이므로 서버가 꺼지거나 재시작되면 접속이 끊길 수 있습니다. 설치 파일과 이 배포 페이지는 GitHub에서 제공됩니다.
