## Android 설치

1. **Download APK**를 눌러 휴대폰에서 파일을 다운로드합니다.
2. 다운로드한 파일을 엽니다. 설치 권한 안내가 나오면 사용한 브라우저 또는 파일 앱에 ‘이 출처 허용’을 설정합니다.
3. 설치 후 Skull King을 실행합니다. 기존 앱이 있으면 업데이트로 설치됩니다.

Android 7.0 이상, 64비트 ARM 또는 x86 기기가 필요합니다. 별도 서버 주소 입력 없이 기본 게임 서버로 연결됩니다.

## iOS 설치

1. App Store에서 Apple의 **TestFlight** 앱을 설치합니다.
2. 위 **Join TestFlight** 링크를 열고 테스트에 참여한 뒤 설치합니다.

사전 기기 등록은 필요하지 않습니다. TestFlight에 이전 빌드가 설치되어 있으면 **Update**를 눌러 최신 빌드로 맞춰 주세요.

## 친구와 플레이

**Create Room**으로 방을 만들고 초대 코드를 공유하세요. 친구는 **Join with Code**로 입장합니다. 2–7명이 Ready한 뒤 게임을 시작합니다.

테스트 서버는 현재 개발용 데스크톱에서 운영 중이므로 서버가 꺼지거나 재시작되면 접속이 끊길 수 있습니다. 설치 파일과 이 배포 페이지는 GitHub에서 제공됩니다.

이 저장소에는 배포 파일과 설치 안내만 공개합니다. 앱·서버 소스는 별도 비공개 저장소에서 관리합니다.
