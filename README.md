## 친구와 플레이

Create Room으로 방을 만들고 초대 코드나 링크를 공유하세요. 친구는 Join Room에서 코드를 입력하거나 카메라로 대기방 바코드를 읽습니다. 2–7명이 Ready하면 시작합니다. Classic에서는 방장이 Add Bot으로 빈자리를 채울 수 있습니다. 팀전은 적어도 두 팀이 있어야 시작할 수 있고, 팀원 개인 점수 평균으로 결과를 정합니다.

게임은 **Oracle Cloud 오사카 서버**에서 운영하며 인터넷이 필요합니다. 앱은 서버 주소 입력 없이 같은 Oracle에 연결합니다.

카드 이름은 **Davy Jones(데비 존스), Siren(세이렌), Hafgufa(하프구바), MobyDick(모비딕), Surrender(항복), Stowaway(밀항자)**입니다.
