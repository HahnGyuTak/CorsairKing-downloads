## 설치

Android에서는 Download APK로 내려받은 파일을 열어 설치합니다. 기존 앱이 있으면 **삭제하지 말고 업데이트**로 설치하세요. 공개 32번과 동일한 서명으로 기존 게스트 계정을 승계합니다. 필요하면 파일을 연 브라우저 또는 파일 앱의 설치 권한을 허용합니다. Android 7.0 이상이며 64비트 ARM 또는 x86_64 기기가 필요합니다.

iPhone·iPad에서는 Apple의 TestFlight 앱을 설치한 뒤 Join TestFlight 링크로 참여합니다. 사전 기기 등록은 필요하지 않습니다. iPad는 가로·세로 화면을 지원합니다.

## 친구와 플레이

Create Room으로 방을 만들고 초대 코드를 공유하세요. 친구는 Join Room에서 코드를 입력하거나 카메라 버튼으로 대기방 바코드를 읽습니다. 2–7명이 모두 Ready하면 시작합니다. 방장은 Add Bot으로 빈자리를 채울 수 있어 혼자 접속해도 Bot과 시작할 수 있습니다.

팀전을 켜면 각자 팀을 선택한 뒤 Ready하세요. 적어도 두 팀이 있어야 시작할 수 있습니다. 팀 결과는 팀원의 개인 점수 평균으로 결정합니다.

게임은 **Oracle Cloud 오사카 서버**에서 운영하며 인터넷이 필요합니다. Android·iOS 모두 서버 주소 입력 없이 같은 Oracle에 연결합니다. 정식 App Store·Google Play 심사와 별개인 공개 테스트 배포입니다.

앱 이름은 **Corsair King**이며 카드 이름은 **Davy Jones(데비 존스), Siren(세이렌), Hafgufa(하프구바), MobyDick(모비딕), Surrender(항복), Stowaway(밀항자)**입니다.
